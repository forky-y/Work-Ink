# ❌ Troubleshooting

---

## Extension Does Not Appear After Installation

Make sure:

- Developer Mode is enabled
- You selected the correct folder
- `manifest.json` exists inside the folder
- Try reinstalling the extension

---

## Extension Shows Error Messages

1. Go to `chrome://extensions/`
2. Click **Details** on Forky Bypass
3. Click **Errors**
4. Read the error message shown by Chrome

---

## Extension Does Not Bypass Links

Possible reasons:

- work.ink updated their protection
- The page needs refresh
- The extension needs updating

Try refreshing the page first.
